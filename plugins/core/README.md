# core — registry, lifecycle, observability

Core infrastructure plugins: event logging, continuity, health, metrics, tracing, lifecycle consolidation, error recovery, hot swap, config validation, and CI integration.

## Plugins

- EventLogger — event persistence
- ContextPrunerPlugin — single authoritative pruner
- HealthMonitoringPlugin — health checks
- MetricsPlugin — metrics collection
- TracingPlugin — distributed tracing
- LifecycleConsolidatorPlugin — lifecycle management
- ErrorRecoveryPlugin — error recovery
- HotSwapPlugin — hot plugin swapping
- ConfigValidationPlugin — config validation
- CIPlugin — CI integration
